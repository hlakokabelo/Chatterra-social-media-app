# Changelog

All notable changes to Chatterra are documented in this file. This changelog is based on the repository commit history from the initial app setup through the latest updates in October 2026.

## [Unreleased]

### Highlights
- Continued polish and reliability improvements across the app shell, profile flows, and mobile navigation.
- Improved auth and profile update behavior.
- Strengthened linting and CI coverage for safer deployments.

## 2026-10

### Improved mobile UX and profile reliability
- Updated the mobile navbar to better match the overall experience.
- Improved the profile update process and related flow behavior.
- Resolved lint and TypeScript issues across the project.
- Added GitHub Actions CI workflow for automated validation.

## 2026-09

### Social experience and search improvements
- Added and refined search functionality across the app.
- Improved community discovery and search flow.
- Added support for URL, mention, and hashtag linkification in posts/comments.
- Added skeleton loading states for a smoother UX.
- Implemented automatic upvoting for newly created posts and comments.
- Added support for linking and better user interaction behavior.
- Updated public profile pages and user profile visuals.

### App quality and developer workflow
- Resolved import errors and TypeScript issues.
- Added ESLint cleanup and formatting pass.
- Added Dependabot configuration.
- Added Vercel Analytics and Insights configuration.
- Updated project documentation and README content.
